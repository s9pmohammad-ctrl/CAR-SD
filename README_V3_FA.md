# CAR SD v3 Adaptive — K2501/NWD

این نسخه بر اساس گزارش واقعی دستگاه K2501 / NWD ساخته شده است.

قابلیت‌ها:
- Self-test خودکار در هر اجرا
- تشخیص سرویس‌های NWD (`nwdaudio`, `nwdmanager`)
- تشخیص property واقعی `persist.sys.ori_music_volume`
- اعمال صدای موزیک و مکالمه
- اعمال مجدد صدا در 2، 5 و 10 ثانیه بعد از Boot برای مقابله با برگشت صدا
- تشخیص LED / RGB استاندارد و کنترل فقط اگر مسیر واقعاً قابل نوشتن باشد
- تشخیص PWM و دما
- جلوگیری از ارسال فرمان حدسی به PWM/MCU ناشناخته

محدودیت مهم:
نسخه MCU به تنهایی مشخص نمی‌کند کدام PWM مربوط به فن است. v3 خودش سخت‌افزار را تست می‌کند و فقط کنترل‌هایی را فعال می‌کند که رابط واقعی و امن آنها ثابت شده باشد. برای فن، تا وقتی کانال فن به شکل قابل اثبات شناسایی نشود، برنامه عمداً write نمی‌کند تا بک‌لایت/آمپلی‌فایر/MCU آسیب نبیند.
