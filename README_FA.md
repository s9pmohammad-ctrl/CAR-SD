# CAR SD — نسخه شروع برای مانیتور Helix / T440

این پروژه یک پایه واقعی Android Studio با Kotlin + Jetpack Compose است و برای نیازهای مطرح‌شده طراحی شده:

- ذخیره صدای پیش‌فرض موزیک
- ذخیره صدای پیش‌فرض مکالمه
- اعمال دوباره صدا بعد از روشن شدن دستگاه (BOOT_COMPLETED)
- تشخیص خودکار مسیرهای استاندارد دما، Fan PWM/RPM و LED از sysfs
- کنترل دستی فن در صورت وجود مسیر PWM
- حالت فن خودکار بر اساس دما
- انیمیشن فن شبیه رابط Helix
- تشخیص Root
- کنترل روشنایی کلیدها در صورت وجود sysfs استاندارد
- رابط فارسی، تیره و مناسب مانیتور خودرو
- آیکون اختصاصی CAR SD با سیلوئت هاچ‌بک

## نکته خیلی مهم درباره Helix T440

کنترل فن و رنگ دکمه‌های فیزیکی در بسیاری از مانیتورهای اندرویدی از طریق MCU اختصاصی انجام می‌شود؛
یعنی API استاندارد Android برای آن وجود ندارد. اگر نسخه فعلی برنامه Fan/LED را پیدا نکند، لازم است
فرمان واقعی MCU دستگاه شناسایی شود.

برای تکمیل دقیق روی دستگاه شما، یکی از موارد زیر خیلی کمک می‌کند:

1. APK قدیمی کنترل فن Helix
2. خروجی `adb shell getprop`
3. خروجی `adb shell dumpsys`
4. خروجی `adb shell ls -R /sys/class/leds`
5. خروجی `adb shell ls -R /sys/class/hwmon`
6. اگر Root دارید: نام پکیج و logcat هنگام تغییر فن/رنگ دکمه‌ها در برنامه قدیمی

## باز کردن پروژه

پوشه را با Android Studio باز کنید و Sync را بزنید.

حداقل Android: 8 (API 26)
Target: Android 15 / API 35

## درباره مشکل صدای 10 در بوت

CAR SD مقدار دلخواه را در SharedPreferences نگه می‌دارد و در `BOOT_COMPLETED` دوباره با AudioManager اعمال می‌کند.
اگر MCU یا سرویس کارخانه‌ای چند ثانیه بعد از Boot دوباره مقدار 10 را تحمیل کند، مرحله بعدی این است که
یک سرویس کوتاه‌مدت پس از بوت اضافه کنیم که مثلاً در ثانیه‌های 2، 5 و 10 مقدار را دوباره اعمال کند.

## ایمنی

بخش Hardware Probe فعلاً فقط مسیرهای استاندارد را پیدا می‌کند. برای جلوگیری از آسیب، برنامه نباید روی مسیرهای
ناشناخته MCU به صورت حدسی write انجام دهد. بعد از شناسایی دقیق سخت‌افزار، یک Hardware Adapter مخصوص T440
اضافه می‌شود.
